# PCCS/TJSP em Reconstrução — apresentação interativa

Este repositório contém a apresentação em HTML/CSS/JavaScript pronta para GitHub Pages.

## Publicação

1. Crie um repositório no GitHub, por exemplo: `pccs-tjsp`.
2. Envie para a raiz:
   - `index.html`
   - `.nojekyll`
3. Abra **Settings → Pages**.
4. Em **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
5. Clique em **Save**.

A URL ficará no formato:

`https://SEU-USUARIO.github.io/pccs-tjsp/`

## Atualizações

Para atualizar a apresentação, substitua apenas o arquivo `index.html` pela nova versão e faça o commit. O GitHub Pages republicará o site e a URL continuará a mesma.
